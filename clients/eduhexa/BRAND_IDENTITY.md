## Visual identity

### Color system (canonical — all creatives)

```css
:root {
  --background-dark: #000000;      /* primary social canvas */
  --primary: #0066FF;              /* electric royal blue — HEXA accent */
  --primary-light: #3385FF;
  --primary-dark: #0047B3;
  --text-on-dark: #FFFFFF;
  --text-muted: #A3A3A3;
  --surface-card: #0A0A0A;
  --accent-glow: rgba(0, 102, 255, 0.25);
}
```

**Note:** Existing WhatsApp creatives use black + `#0066FF`. Pipeline renders use Brand DNA tokens; `background_mode: dark` maps to `#000000` (not Swayam navy).

### Typography
- **Headlines:** Bold geometric sans (Inter, DM Sans, or similar)
- **Body:** Clean sans, high readability at mobile scale
- **Style:** Editorial — large headline, tight subline, minimal decoration

### Logo
- **Asset:** `clients/eduhexa logo.png` (HEXA wordmark, blue on transparent/dark)
- **Placement:** Bottom-right on social posters (~20% canvas width)
- **Workflow:** Generate without logo; composite post-generation

### UI / layout patterns
- Dark canvas + blue hexagonal or circuit motifs (subtle)
- Abstract vector scenes — classrooms, desks, books — not stock photos
- Stat callouts with single dominant number
- Carousel covers: one provocative line per slide

### Imagery guidelines
**Prefer:** Editorial vector, geometric minimalism, Indian school context (abstract), data callouts, leadership-facing tone

**Avoid:** Stock handshakes, cheesy graduation caps, “India’s No.1”, sci-fi AI brains, fake rankings, competitor logos, invented survey stats without source
