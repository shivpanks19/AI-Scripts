# EduHexa — Research archive

Weekly **Community Pulse** syntheses and paired **image prompts** for WhatsApp/social creatives.

## Layout

```
research/
├── community-pulse-{YYYY-MM-DD}.md   # Reddit/web research synthesis
├── image-prompt-{slug}-{month}-{year}.txt   # Generation prompt for paired poster
└── README.md
```

## Usage

- **Content calendar / strategy:** Pull latest `community-pulse-*.md` for weekly angles.
- **Image generation:** Match `image-prompt-*.txt` to the week's theme; logo composited post-generation from `clients/eduhexa logo.png`.

Canonical path: `clients/eduhexa/research/`
