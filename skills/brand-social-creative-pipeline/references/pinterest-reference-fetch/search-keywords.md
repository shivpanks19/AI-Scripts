# Pinterest search keyword recipes

Quick lookup when building `search-brief.json` from `BRAND_IDENTITY.md`. Always combine **category** + **format** + optional **platform**.

## Query formula

```
{industry_or_domain} {product_category} {format} {platform}
```

| Token | Examples |
|-------|----------|
| `industry_or_domain` | B2B SaaS, edtech, nonprofit, fintech, D2C |
| `product_category` | CRM, CSR, LMS, payments, coaching, analytics |
| `format` | social media post design, carousel, instagram creative, linkedin post |
| `platform` | linkedin, instagram (optional) |

## Layout-diversity search modifiers

Add when a specific archetype is missing from the first 3 pins collected:

| Missing layout | Add to query |
|----------------|--------------|
| Dashboard / UI mockup | `dashboard mockup social post` |
| Stat / KPI | `stat card social media post` |
| Dark editorial | `bold typography linkedin carousel black` |
| Phone mockup | `app mockup instagram post design` |
| Gradient cards | `gradient KPI card social media SaaS` |

## Pinterest search URLs

```
https://www.pinterest.com/search/pins/?q={url_encoded_query}
https://www.pinterest.com/ideas/{topic-slug}/
```

Use WebSearch fallback: `site:pinterest.com {query}`
